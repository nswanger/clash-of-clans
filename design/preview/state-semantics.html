State semantics

Five marks, and a rule that keeps them marks. Colour states an evaluation or a category — it never raises a notice. If the user cannot act on it, it is not a notice.
The five marks
Qualified

Success — an evaluation that came out well and is earned. 8★ bonus secured.moss 101° · chroma 44%

Not applied

Caution — in progress, your move. A swap not yet applied in game, unsaved edits, an unlocked plan near a deadline.violet 257° · chroma 38%

Out of date

Danger — action required now. A stale plan, a failed refresh, blocked collector access.rust 16° · chroma 91%

Observed

Info — a category. Neither good nor bad. An access role, an invitation status, lineup provenance.slate 208° · chroma 32% — the quietest by design

—

Unknown — absent evidence, carrying no hue. Always an em-dash in muted, badge and cell alike, so it never reads as zero.no hue · same as muted, differs by glyph

Info never raises a notice. An info-coloured bar is precisely the chrome the notice budget exists to remove, so info is confined to categorical marks. That is also why it is the lowest-chroma state in the set.

Why activity is never negative

The domain's three activity values are observed, no_change and unknown — note it is no_change, not “inactive.” The data layer already refuses to read absent evidence as poor performance, so no activity value may take a negative colour. Missing signup opportunity is not weak activity; it is a missing opportunity.
